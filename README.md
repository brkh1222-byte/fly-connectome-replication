# fly-connectome-replication

Do whole-brain connectome simulations replicate across individual flies? This repo runs the Shiu et al. (2024) Drosophila LIF model on FlyWire, BANC and the male CNS.

📄 **Read the research proposal:** [PROPOSAL.md](PROPOSAL.md) · **Tasks:** [TASKS.md](TASKS.md)

## Plan

Reproduce Shiu on FlyWire v783 → GPU port (PyTorch) → standardise BANC and the male CNS → cell-type matching → replicate the feeding and grooming predictions → H100 robustness sweeps and shuffled nulls
